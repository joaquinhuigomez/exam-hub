# SOA-C03 Content Spec (shared by all content agents)

Exam: AWS Certified CloudOps Engineer – Associate (SOA-C03; successor to SysOps Administrator SOA-C02, launched 30 Sep 2025). 65 questions (50 scored + 15 unscored), 130 min, pass 720/1000, $150. Formats: multiple choice (4 options, 1 correct) and multiple response (5 options, 2 correct — stem MUST say "(Choose two.)"). NO hands-on exam labs in C03.

Learner: Joaquin — intelligent, ADHD, holds AWS Cloud Practitioner, Solutions Architect Associate (passed yesterday), GenAI Developer Professional. Strong on architecture; the GAP for this exam is OPERATIONS MECHANICS: how things fail, what the error/status/metric looks like, which knob fixes it, which console/CLI step comes first. Learns by doing: scenario → diagnose → see WHY every option is right/wrong. Wants decision rules, troubleshooting flowcharts, and the numbers/defaults that get tested.

## What makes this exam different from SAA (write to this)
SAA asks "which architecture". SOA asks "it's broken / it's slow / it's non-compliant — what do you check or change?" Favour stems like: "An alarm did not trigger…", "The stack is stuck in UPDATE_ROLLBACK_FAILED…", "Instances do not appear in Systems Manager…", "Users get HTTP 503 from the ALB…", "Flow logs show REJECT…", "CloudFront cache hit ratio is low…", "PITR restore was performed but the application still fails…". Test defaults (cooldown 300 s, ALB idle timeout 60 s, deregistration delay 300 s, health-check thresholds, CloudWatch 5-min vs 1-min detailed monitoring, PITR 35 days, KMS rotation, ACM validation methods), prerequisites (SSM agent + instance profile + network path), and the order of operations.

## Domains and weights (official)
- D1 Monitoring, Logging, Analysis, Remediation, and Performance Optimization — 22%
  - 1.1 Implement metrics, alarms, and filters (CloudWatch, CloudTrail, Managed Prometheus; CloudWatch agent on EC2/ECS/EKS; alarms incl. composite alarms and actions via EventBridge; cross-account/cross-Region dashboards; SNS notifications)
  - 1.2 Identify and remediate issues (automated remediation with CloudWatch + Lambda + Systems Manager + CloudTrail + Kiro + AWS DevOps Agent; EventBridge routing/enrichment/rule troubleshooting; Systems Manager Automation runbooks)
  - 1.3 Performance optimization (compute via metrics/tags/Compute Optimizer; EBS metrics and volume-type tuning; S3 performance — DataSync, Transfer Acceleration, multipart, lifecycle; shared storage selection EFS/FSx and EFS lifecycle; RDS Performance Insights + proactive recommendations + RDS Proxy; EC2 placement groups, ENA/EFA, instance store)
- D2 Reliability and Business Continuity — 22%
  - 2.1 Scalability & elasticity (EC2 Auto Scaling mechanics, ECS/EKS scaling, caching with CloudFront/ElastiCache/DAX, RDS/Aurora/DynamoDB scaling)
  - 2.2 HA & resilience (ELB + Route 53 health checks configuration & troubleshooting, Multi-AZ, fault tolerance)
  - 2.3 Backup & restore (AWS Backup plans/vaults/cross-account/cross-Region/Vault Lock; snapshots for EC2/EBS/RDS/DynamoDB/S3; PITR; RTO/RPO; S3 & FSx versioning; DR patterns backup-restore/pilot light/warm standby/active-active)
- D3 Deployment, Provisioning, and Automation — 22%
  - 3.1 Provision & maintain (AMIs and container images with EC2 Image Builder; CloudFormation & CDK; remediate deployment issues — subnet sizing, CloudFormation errors, permissions; multi-Region/multi-account sharing with RAM and StackSets; deployment strategies; Terraform & Git basics)
  - 3.2 Automate management (Systems Manager — Run Command, Automation, State Manager, Patch Manager, Maintenance Windows, Inventory, Parameter Store, Session Manager, OpsCenter, Fleet Manager; event-driven automation with Lambda, S3 Event Notifications, EventBridge, AWS DevOps Agent)
- D4 Security and Compliance — 16%
  - 4.1 Security & compliance tools/policies (IAM password policy, MFA, roles, federation, resource policies, policy conditions; troubleshoot access with CloudTrail, IAM Access Analyzer, policy simulator; Organizations, SCPs, Identity Center; Trusted Advisor security checks remediation; Config conformance packs, Region/service restrictions)
  - 4.2 Protect data & infrastructure (data classification; KMS encryption at rest incl. troubleshooting; ACM encryption in transit; secrets in Secrets Manager / Parameter Store; reports and findings from Security Hub, GuardDuty, Config, Inspector, AWS Security Agent)
- D5 Networking and Content Delivery — 18%
  - 5.1 Networking features (VPC: subnets, route tables, NACLs, SGs, NAT GW, IGW, egress-only IGW; private connectivity: VPC endpoints, PrivateLink, peering; audit network protection: DNS Firewall, WAF, Shield, Network Firewall; network cost optimization)
  - 5.2 DNS & content delivery (Route 53 Resolver incl. inbound/outbound endpoints; routing policies, configurations, query logging; CloudFront and Global Accelerator)
  - 5.3 Troubleshoot connectivity (VPC configs incl. TGW and NAT; logs — VPC Flow Logs, ELB access logs, WAF logs, CloudFront logs, container logs; CloudFront caching issues; hybrid/private connectivity issues; CloudWatch network monitoring incl. Network Monitor, Internet Monitor, Reachability Analyzer)
